# 书目分类与选书方式提案

状态：2026-11-05 经用户选择推荐方案，首期代码已在本地实现并验证；尚未提交、部署或写入线上分类。以下保留设计依据与实施边界。

## 最终导航表现（取代下文早期入口草图）

用户于 2026-11-05 明确要求题材作为页面第三级导航，而非三级分类树：第一级为书架/发现/概况，第二级为书籍/演讲，第三级在书籍下显示全部与十个题材。它在首页和结果页均常驻，位于搜索上方。题材沿用现有 `subTabs` 的文字、绿色下划线与选中加粗，不使用浅绿按钮背景或圆角块。手机和电脑均保持单行横滑，内容溢出时两端显示左右箭头，到达边界的一侧禁用，选中项自动保持可见。用户进一步要求移除 All books 与 Filter 按钮：完整书目统一通过第三级“全部”标签进入；演讲直接显示完整列表。搜索保留，旧筛选地址仍可读取和清除，但不再提供高级筛选弹层。旧的六格入口已移除，分类数据和后台编辑逻辑不变。

默认进入 `/discover/` 或 `/discover/novels/` 时直接选中“全部”并显示完整书籍网格，与手动点击“全部”的视觉和书目范围一致；不再切换到另一套新书/系列陈列首页。默认进入与点击“全部”都保留分页加载，系列链接和历史集合地址仍能进入各自列表。用户随后确认只在书籍 All 顶部保留一条紧凑新书横排（最多12张书封、按首次 `added` 排列），下方仍为完整网格；不恢复大推荐位或多个系列横排。题材、搜索、系列、专题、历史高级筛选和演讲页不显示该横排；缺少有效上架日期时不凭更新时间填充。横排“查看全部”进入按上架时间排列的新书集合，不嵌套重复横排。

### 新书横幅轮播（后续调整）

PR7 合并后，用户要求取消多封面新书横排，复用原 `FeaturedBook` 单本横幅：最近6本按首次上架时间排列，每6秒自动前进，可左右切换、选择位置、暂停/播放。单本不自动播放，缺失有效上架日期不猜测。横幅仍仅出现在书籍 All，上方搜索与题材导航、下方完整网格不变。位置指示为横幅内部底部居中的小圆点，不另占下方一行；左右箭头在横幅两侧，小型暂停/播放在右下角，取消额外的“查看全部”控件。

鼠标悬停、页面隐藏、打开详情时临时暂停；键盘聚焦、手动切换或暂停会停止自动播放，须显式播放恢复。减少动态效果与墨水屏主题禁用自动计时和切换动画，手动切换仍可用。每次只挂载一个以复合目录键标识的原横幅，避免简介/色调串书和批量预取。

### 题材内的系列与搜索（后续确认）

题材页只显示逐本书卡网格，不重复显示新书横幅。默认顺序按稳定轮次交错：每个已标系列每轮贡献一册，系列内部按册次排列；无系列标注的书各自独立占位，不能据此称为独立作品。所有书仍可分页找到，不随机重排。书卡上的系列文字可点击，进入完整系列后按册次显示，不再受原题材限制；封面/书名仍打开单本详情。历史地址显式指定其他排序时保留该排序，不强制交错。

搜索覆盖当前书籍或演讲分区，开始输入时清除题材、集合、作者、系列与难度等限制；第三层回到“全部”。清空搜索仍停留全部结果。点击题材则退出搜索，显示该题材。旧的带题材/系列限制的搜索地址也按全分区搜索归一化，避免存在但搜不到的书。

## 目标与现况

让读者先按兴趣找到书，再用阅读难度、作者或系列缩小范围；管理员能批量维护题材，而不是把每一种兴趣都做成首页横排。

本轮从公开 live catalog 只读统计到：257 条书目，其中 210 本书、47 篇演讲。210 本书里，99 本有系列标注，111 本没有系列标注。后者并不等于独立作品：Percy Jackson 的五本书等仍有系列信息待补。当前两个目录都没有题材字段。

首页配置目前含八个小说系列横排及一个 Roald Dahl 自选横排，演讲区另有 TED 横排。因此首页较长、同一本书在陈列和全部书目中重复出现，不只是视觉问题，也与信息结构有关。

## 推荐结构：类型、题材、系列、难度各司其职

| 维度 | 回答的问题 | 推荐处理 |
| --- | --- | --- |
| 内容类型 | 读书还是读演讲？ | 前台“书籍 / 演讲”；保留内部 novel/speech 和现有下载配额 |
| 题材 | 想看什么故事？ | 固定的约十类；一本书可属于多类 |
| 系列 | 想连续读哪套书？ | 保留系列名、册次，独立于题材 |
| 阅读难度 | 当前英语水平是否合适？ | 复用现有 Lexile 筛选，不混入题材 |
| 首页专题 | 管理员这次想推荐什么？ | 复用自选书目陈列；不自动变成题材 |
| 个人阅读状态 | 已读完哪些书？ | 保留个人书架现有状态，不写进公共分类 |

已有回忆录等非虚构作品，所以前台把 Novels 改称 Books 更准确。这只是显示名称调整：旧地址、内部 category、七本书/七篇演讲配额保持兼容，不重新分配已使用的额度。

## 首批题材

推荐先使用以下十类。英文 slug 为稳定身份；中英文名称来自界面词典，不在每本书里重复保存。

| 中文名称 | 英文名称 / slug | 范围 |
| --- | --- | --- |
| 奇幻魔法 | Fantasy / fantasy | 魔法、神话和幻想世界 |
| 冒险生存 | Adventure / adventure | 探险、旅程、求生 |
| 推理悬疑 | Mystery / mystery | 谜案、调查和以解谜为核心的悬念 |
| 科幻故事 | Science fiction / science-fiction | 科学设定、未来社会、反乌托邦 |
| 现实成长 | Realistic fiction / realistic | 现实生活、成长、校园和家庭关系 |
| 历史战争 | Historical fiction / historical | 以历史时代、历史事件或战争为背景的小说 |
| 爱情情感 | Romance / romance | 爱情关系是主要叙事线索 |
| 动物故事 | Animal stories / animals | 动物或人与动物的关系是主要叙事线索 |
| 惊悚恐怖 | Horror & thrillers / horror-thriller | 恐惧、威胁、惊悚是主要阅读体验 |
| 传记纪实 | Biography & nonfiction / nonfiction | 回忆录、传记及其他非虚构作品 |

分类规则：

- 每本已审核书籍标 1–3 类，不强制唯一归属，也不额外增加“主分类”。
- 依据全书主要内容，不因为偶尔出现动物、战争或爱情就附加题材。
- 系列可批量预填，但需要逐册检查例外，不能永久由系列名自动推断。
- 首期不把“经典”“适合初学者”“幽默”“热门”混入题材；经典/幽默等可以做专题，难度继续用 Lexile。
- 老书目可以暂时无题材：始终保留在全部书籍与搜索里；后台显示“待分类”。不公开创建“其他”兜底桶。
- 演讲不套用小说题材；其主题分类不在首期范围内。
- Lexile 只表示语言难度，不等于年龄适宜性。成人作品不因数值低就标成“适合初中生”。

示意标注，不是已经完成的逐书审核：Harry Potter 可标奇幻魔法、冒险生存；Wonder 可标现实成长；Flipped 可标现实成长、爱情情感；Educated 可标传记纪实；Treasure Island 可标冒险生存。

## 发现页：入口页和结果页分工

不改现有配色、字体、书封与详情弹层；只调整入口和内容组织。

### 入口页

```text
书籍                         演讲
[ 搜书名或作者               ] [筛选]

按题材选书                           全部题材
[奇幻魔法] [冒险生存] [推理悬疑]
[现实成长] [历史战争] [动物故事]

最近上架                            查看全部
一小排书封

系列阅读                            查看全部系列
[Harry Potter · 7本] [Magic Tree House · 52本]
每个系列是一个入口，不展开每一册

编辑精选（可选，最多一个专题横排）

[ 浏览全部书籍 ]
```

- 示例六个题材入口的最终选择和顺序，应在首批标注完成后按覆盖情况确定；“全部题材”始终能看到完整列表及数量。
- 手机上入口可排两到三列，避免十个按钮塞成一条很长的横向滚动条；桌面利用现有内容宽度。
- 首页最多两排逐书陈列（最近上架、一个编辑专题），不再把每个系列和全部书籍接着铺到底。
- 系列入口用代表封面、系列名称和本站收录册数；册数不是宣称整套已收齐。不能保证首册时，不把代表封面误称“第一册”。
- 首页不再同时放一个相同新书的大推荐位和紧邻的新书横排。
- Roald Dahl 等作者合集属于专题，不冒充系列或题材。

### 题材 / 全部书籍结果页

```text
返回发现
奇幻魔法                         共 N 本
[ 搜书名或作者               ] [筛选]
[奇幻魔法 ×] [当前难度 ×]          清除筛选

封面网格：每本书只出现一次
```

- 点题材、搜索、全部书籍或系列入口，都进入明确的结果状态，不在下面继续追加首页推荐横排。
- 首期题材单选，选择另一题材即替换；一本多题材的书可以出现在多个题材页，但同一结果集只出现一次。
- 题材、难度、作者、系列、搜索之间取交集。筛选弹层里保留现有高级条件，不把所有下拉框堆在页面上。
- 默认逐本展示，不在题材结果中自动折叠系列，以免读者看不到目标册次；进入具体系列则按册次排序。
- 题材数量统计该题材的独立书目，不把各题材数量相加当总书数。筛选后数量以实际交集为准。
- 无结果时明确给出“清除难度”等操作；不悄悄去掉用户的条件。
- 题材、查询与筛选状态纳入可恢复的地址/历史状态，详情关闭、后退和刷新不会回到未经筛选的首页；实现时扩展现有手写 router，不照搬尚不支持的 query 示例。
- 继续沿用分页挂载、封面可见后加载、会话缓存，不为每个题材下载整份词表。

## 后台：一个轻量书目分类管理页

复用现有后台，不新建独立管理系统。

```text
书目管理
[书名或作者] [题材] [系列] [只看待分类]

选择  封面/书名         题材                系列/册次
□     Wonder          现实成长            —
□     Harry Potter…   奇幻魔法 / 冒险生存    Harry Potter / 1

已选 N 本   [添加题材] [移除题材] [替换题材]
                                   [预览更改] [保存]
```

- 单本可编辑题材，批量操作明确区分“添加”“移除”“替换”，避免误清已有分类。
- 系列可在此补全；批量设系列名后仍要确认各册次，不能给整组书写同一个册次。
- “待分类”“缺系列信息”只是管理视图，不增加数据库任务队列或定时工作流。
- 保存前显示受影响书籍和前后变化，后端校验目录身份、题材白名单、上限及冲突。
- 只提供受限元数据更新，不把整份词表上传接口当分类编辑器，也不接收任意字段覆盖。
- 原有“系列陈列”管理改称“首页陈列”更准确，与分类维护分开；保留其专题选择能力，不再默认全部展现为逐书横排。

## 数据与成本

在两个现有 live catalog 行增加可选字段：

```json
{
  "id": "example-book",
  "genres": ["fantasy", "adventure"]
}
```

- category、series、seriesNumber、lexile 保持各自语义，不重用 category 承载题材。
- 保存字段使用固定英文 slug；前端未知 slug 忽略、不影响书籍展示；管理端拒绝未知、重复和超过上限的值。
- 书目目标始终使用 catalog + id，不靠书名或裸 id 批量写入。
- 元数据保存复用对应 catalog 写锁，锁内读取最新目录、只应用明确的行级更改，并检查提交基线以拒绝冲突；保留所有未修改字段。
- 不改变 EPUB/词表字节、hash、rev、书目行 updated/added，不制造“词表有更新”或“新上架”。必要时仅更新目录级更新时间。
- 如一次操作涉及两个 catalog，分别发布和汇报结果；不宣称跨两个对象的原子提交。
- 分类存于原有 R2 catalog，客户端本地筛选，不增加读者每点一个题材就查询 D1 的链路。管理员保存使用现有鉴权/锁仍有少量 D1 操作，不承诺零消耗。
- 目录增加少量文字字段，不下载 EPUB 或词表。实际冷启动和客户端负担需在实现后验证，不给出未测量的性能百分比。
- 所有词表/书籍上传路径与巡检写回都要验证保留 genres，避免下次发布词表时分类丢失。

## 个人书架边界

首期重点是全站公共书目分类和发现页选书。个人书架继续保留“继续阅读”、完成状态、搜索、难度与系列筛选，不重做阅读首页。

个人书架以后可以复用公共题材，但不能只新增一个同步 Book 字段就宣称完成：要处理现有已下载书籍、复合书目身份、离线缓存和无匹配自导入书。若纳入后续范围，应采用轻量派生元数据，缓存缺失不能阻断阅读，也不能重新扫描全文来猜题材。个人自建书单/文件夹是另一种功能，不与公共题材混用。

## A / B 复核后的取舍

A 与主对话支持目录内可选 `genres[]`、受限元数据编辑及首期聚焦发现页；B 最终也接受每本最多三题材、结果平铺、书架题材筛选后置。以下仍是主对话的推荐，不把分歧写成全员一致：

- 采纳 B 的首页/结果状态硬边界：任何题材、集合、搜索或筛选生效后，只显示结果网格，不继续叠加推荐横排。陈列应替换、收敛现有内容，不是在现有九条横排上继续加模块。
- 采纳 B 的数量与无障碍建议：题材入口是按钮组而非嵌套一级 tab；选中态可被辅助技术读取。数量按各自结果计算，目录尚未加载不能误显示“没有书”。
- 保留十类候选，暂不把推理与恐怖强行合并；这是有不同选书意图的两类，是否在入口显露应在逐书标注后决定。B 提议的九类可作为精简备选，尚无完整标注计数支持任一方案更优。
- 保留每本 1–3 个题材，不增加 primary。分类是入口而非互斥分桶，多题材不会要求多份书籍记录，也不意味着一个结果集重复。首期不做题材多选。
- 保留轻量后台分类维护。用户明确提出书目管理需求，仅提供上传参数会把日常维护留给代码或脚本；但不做可自由创建无限标签的通用 CMS。
- 保留“首页系列入口”作为推荐方向，但不依赖未核验的系列数据。系列名、代表封面和本站收录数需先审核；没有把握的系列不生成卡片，也不声称完整收齐。系列卡替换长横排，不与其重复叠加。
- 不采纳“最大系列超过 25% 就自动切分组”“生活超过 35% 就拆分类”“少于三本隐藏”的固定阈值。它们是未验证的经验数，不是现有事实或用户要求；先统计、检查真实布局，再决定。读者主动选择的排序不应被暗中替换。非空小题材仍应能从完整题材入口找到。
- 保留六个主要入口加完整题材列表的草图。B 更偏好一条横滑；实现前可用手机原型比较可发现性，目前不把交互形态视为已经验证。只能选择一种主要题材入口，不能同时叠加按钮格与长条。
- 成人内容适宜性不由题材或 Lexile 推断。首页推荐要人工审核，但“没有上首页”不构成适龄保证，也不自动授权移除现有书目。

## 落地顺序与验收

1. 确认题材名称和边界，先做一份完整 live 书目标注草稿；草稿中单列不确定项和系列缺失项，不把书名猜测直接写到线上。
2. 实现兼容读取、受限元数据编辑、题材筛选与首页/结果页分离，补前后端与交互测试。
3. 先部署兼容代码；经过授权与排他写入协调后，备份最新 live catalog，只发布审核通过的分类和系列元数据，回读比较差异。
4. 验收每本书仍能从全部书籍找到、多题材不重复、系列顺序正确、筛选可恢复、旧 catalog 可读；确认已下载书、笔记、生词、进度和下载配额不变。

首期实现包括十类题材读取、发现入口/结果分离、系列入口、可恢复筛选地址和后台元数据草稿/预览/批量保存。公开目录尚未补标题材，因此部署代码本身不会自动产生分类结果；无题材旧书仍可从全部书籍和搜索找到。后续线上书目补标、提交推送和部署需要单独授权；本轮没有修改书籍内容或线上目录。
