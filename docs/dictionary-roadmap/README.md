# 词典功能开发准备文档索引

当前阅读器词典功能仍在需求讨论阶段，未因这些文档而实施新API、数据库或巡检权限。

## 当前入口

- **[第10版：前端先行接入](v10/FRONTEND_INTEGRATION.zh-CN.md)**：正式词卡默认启用顶部更多、旧释义社区标签，并预留类型化四状态面板接口。保留原署名、反馈与收藏；标准数据及投票仍待后端，不定义数据库、不发布线上数据。

- **[第9版：四种内容状态](v9/FOUR_STATES.zh-CN.md)**：当前规则。只有标准时显示一条，错误点击直接报告并允许独立社区投稿；只有社区时也提供全部标准候选；两者都有则都显示；两者都无则直接返回全部候选。覆盖第8版冲突操作规则，仅本地原型。

- **[第8版：语境选择与释义分工](v8/CONTEXT_CHOICE.zh-CN.md)**：当前交互规则。👍 明确表示符合此处语境，隐藏公开票数，成功后提示等待核对；标准侧仅允许无文字的“这里没有对应的义项”，社区侧保留原内容反馈。补全新词典已有标准映射时的单条直接展示规则。保留第6、7版布局和署名规则，仅本地原型，未接后端或部署。

- **[第7版：社区释义统一口径](v7/COMMUNITY_TERMINOLOGY.zh-CN.md)**：全部已上架书籍现有解释统一为社区释义，不再设旧版解释分类；原署名保留。用户最终要求布局维持第6版现状，不实施单一释义也加标签的提议。覆盖历史文档中的旧版解释展示规则。
- **[第6版：推荐释义／词典义项分标签预览](v6/WORD_CARD_TABS_PREVIEW.zh-CN.md)**：当前UI入口。社区或固定标准构成推荐内容；未固定候选独立在词典页，只有两类内容并存才显示标签。社区竖线移除，行末问号恢复原反馈入口。覆盖第5版连续上下堆叠的展示设计，仅本地原型。
- **[第5版：单词弹窗原型展示调整](v5/WORD_CARD_PROTOTYPE.zh-CN.md)**：最新UI规则覆盖第4版“标准在前”的布局：社区/旧解释在上，标准候选在下；增加明确点赞用途提示，外链收进顶部更多入口。仅本地原型，尚未接后端或部署。数据与权限规则仍参考第4版。
- **[功能 v1 开发准备说明 · 讨论记录第4版](v4/DICTIONARY_V1_DEVELOPMENT_BRIEF.zh-CN.md)**：当前规则入口。一次有效位置点赞即可触发夜间巡检，由agent核对原句后选择正确的已有义项并固定；取消5人/70%门槛，不按票数盲目固定。保留标准词典只读权限、唯一社区解释、旧版来源标签、收藏与点赞独立及原句限量查询。与历史讨论冲突时以此为准。
