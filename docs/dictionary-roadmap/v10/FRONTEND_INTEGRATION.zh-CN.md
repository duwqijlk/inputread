# 前端先行接入

日期：2026-11-09。用户批准采用第9版四状态，先修改前端，后端和数据库格式尚未确定。本版不定义数据库表、HTTP协议、R2分片或词表发布格式。

## 本轮正式前端

- WordCard 默认使用顶部“更多词典”，收起 Longman / Webster / Pictures；保留发音、收藏、关闭、短语切换和句子帮助。
- 现有词表的已命中解释统一显示为“社区释义”，正文、词性、真实贡献者 CreditLine、问号反馈和现有收藏保持原流程。
- 旧词表的 senseIndex 和 others 不是新标准 sense ID 或完整候选，不能转为标准释义或拿来点赞。
- WordCard 增加类型化 sensePanel 属性，接受已解析的 WordSensePanelProps。该接口只是 React 展示契约，不是后端响应格式；组件不 fetch、不读写数据库。
- sensePanel 已提供时，直接渲染四状态面板；未提供时使用现有社区 WordMeaning。更换选词、书籍或短语目标时重新挂载面板，避免标签／反馈状态串到新位置。
- 社区反馈回调区分 too_hard 与 wrong_meaning；标准错误、候选无匹配、社区投稿各自独立，不能复用为修改标准词典。
- 社区署名支持 communityCredit 插槽，可传现有 CreditLine，以真实公共贡献者标识解析；不将公开ID、邮箱当作展示名。

## 仍待后端确定后接入

- 真实标准定义查询、按 lemma/form 获取全部候选、准确位置映射解析。
- 位置投票和回执、标准错误无文字报告、候选无匹配报告、社区投稿与审核。

第9版四种内容组合继续有效。当前缺少标准服务是接入未完成，不是新增第五种产品状态；不得宣称真实阅读器已能返回标准候选或持久化新投票。
