# 单词弹窗：推荐释义与词典义项分标签预览

日期：2026-11-08。状态：仅本地真实组件原型，未接词典资源、真实投票或反馈后端，未提交/部署。本版展示规则取代v5中的连续上下排列及社区左侧竖线，数据身份与权限仍遵守v4。

## 内容与默认视图

| 位置状态 | 默认内容 | 导航 |
| --- | --- | --- |
| 社区/旧解释存在，标准尚未固定且有候选 | 推荐释义，只显示社区/旧解释 | 推荐释义、词典义项两个文字下划线标签 |
| 社区/旧解释＋固定标准 | 推荐内容内先社区后标准，两条展开 | 不显示只有一页的标签栏 |
| 只有固定标准 | 固定标准解释 | 不显示多余标签栏 |
| 没有社区，也没有固定标准，有候选 | 全部词典候选及位置点赞 | 直接显示词典内容，无空推荐标签 |
| 只有社区/旧解释，标准无匹配 | 社区/旧解释 | 不创建空标准页 |
| 两者都没有 | 未收录/加载/失败提示及补写入口 | 不创建空推荐页 |

推荐区不显示未确认候选。词典区使用更紧凑的词性＋释义分隔列表，明确说明点赞用于选择适用于本句的意思；固定后不返回整词候选，也不提供投票。

## 社区反馈

去掉社区前方竖线。问号回到解释最后一个词之后，点击展开“太难懂／不对／Write my own”选项，不在整份候选列表下孤立放置补写操作。用户署名独立保留，无署名旧稿标为旧版解释。

没有社区解释时仍提供Write my own，不能因为没有问号的挂载文字而丢失补写能力。所有动作仅内存演示，不发送现有生产反馈。

## 外链与布局

外部词典仍默认收进词头旁三横线更多按钮，展开后可用。词头、发音、收藏、关闭和更多保持现有真实WordCard；只在原内容滚动区域切页。标签使用项目现有subTabs文字＋下划线，不额外使用胶囊/卡片背景。

标签支持键盘左右键、Home/End及可访问的tab/tabpanel关联；切页不改变投票作用域。每个位置的父组件按位置/场景重置展示状态，不能跨位置继承选择。
