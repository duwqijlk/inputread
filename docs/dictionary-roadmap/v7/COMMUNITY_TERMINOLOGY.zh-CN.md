# 社区释义统一口径

日期：2026-11-08。当前为本地原型和开发准备规则，未迁移或修改线上数据。

## 本轮确认

- 所有已上架书籍目前已有的释义，包括之前由agent生成的解释，都统一归类为**社区释义**。
- 不设置“旧版解释”这一第三种释义分类，也不在词卡或预览场景中显示该标签。
- 标准释义仅指独立维护标准词典中通过已有sense ID解析出的释义。
- 已有用户贡献署名继续按原有From来源展示；未署名内容不虚构作者。不因统称社区释义就把所有旧解释认作某位用户的贡献。
- 历史来源可以作为审计信息保留，但不是面向用户的另一释义类别。

## 布局不变

用户随后说“算了，维持现状”，因此不实施上一条提出的单一释义也必须显示标签栏的变更。保持第6版现有预览布局：社区释义和未固定候选同时存在时显示推荐/词典两个标签；两项都确定时直接在推荐内容中显示；只有一种内容时不增加多余标签。

社区释义末尾问号、Write my own入口、顶部更多词典、位置点赞与固定后关闭投票的规则均不变。本轮仅统一来源称谓和原型类型，不修改生产词卡默认行为、收藏或线上词表。

本规则覆盖历史文档中“旧版解释”的展示及分类描述；前版文档保留为历史，不可再据其增加旧版释义分区。
