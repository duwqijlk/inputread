# 语境选择与释义分工

日期：2026-11-08。用户批准执行本轮建议。本轮仅更新本地真实组件原型和开发规则，不接真实接口，不发布线上数据。

## 位置点赞不是热度评价

- 保留描边 👍，含义明确为“符合此处语境 / Fits here”，不是评价解释写得好、不是全站词义热度。
- 候选页询问“哪个意思符合这里的用法？”。只点击按钮才选择，点击正文或整行不触发。
- 第一版不展示公开票数；后台位置投票与审计数据仍可保留。候选保持稳定顺序，不因投票重排。
- 单用户单位置一票，可改选、可取消；资格仍为登录且邮箱已验证。
- 请求中禁重复；成功回执后才更新选择。选中显示“选择已保存，等待核对”，取消显示“选择已取消”。失败不能声称保存成功。
- 一次有效选择即可触发夜间核对，不按最高票直接固定。维护者核对准确位置与原文后可选择其他正确的已有 sense ID；没有合适义项不强行绑定。
- 标准区域只有“这里没有对应的义项”这一无内容报告入口，与选择独立。不打开表单，不允许携带解释文字，不是负票、不创建义项。不论固定单义项还是未固定候选都可使用。
- 不存在本地草稿产品功能。只有社区释义保留原有问号、Too hard / Wrong / Write my own；标准区域不出现这些入口。原型中的社区表单只演示提交交互，明确未发送。
- 收藏继续独立，不以投票为前提；反馈入口不因没有投票资格而消失，实际提交的鉴权由后续接口设计决定。

## 社区与标准的分工

- 社区释义：用简单英文帮助理解当前位置；可以补充原句语境，不是标准义项候选。
- 标准释义：独立词典中已有 sense ID 对应的稳定含义。标准义项存在不表示它已确认适用于此处。
- 来源与确认状态是不同维度。From 只表示真实贡献者，不是准确性认证。旧书中所有原有解释继续统一归为社区释义；真实署名保留，无署名不虚构用户。
- 未固定时返回全部合法候选，不因已有社区解释而省略；默认推荐页先帮助阅读，词典页中的选择是可选贡献，不是必答题。
- 后续新生成的书籍词典以已有标准 sense ID 进行位置映射；此前已上架词表的原有解释归社区，不能把新映射误当社区内容。
- 只有标准且位置已映射：直接显示“标准释义”、词性、该 ID 对应的一条定义及“这里没有对应的义项”。无社区标题、无标签栏、无投票、无 From、无 Write my own、无文字反馈。
- 只有标准但未映射：直接显示全部合法标准候选和语境选择按钮；无空推荐页和标签栏。只有这种未固定状态返回全部候选，不能把新词典已有的位置映射丢掉。
- 只有社区：直接显示一条社区释义、原署名和原问号反馈，不增加标签栏。
- 社区与未固定标准候选并存：推荐/词典两标签，默认推荐；社区表单只能在推荐页，不能泄漏到标准候选页。
- 固定后不再投票，标准侧只保留无内容的“这里没有对应的义项”报告。不把“已固定”承诺成永远不可能出错。
- 同时存在社区与固定标准时，社区在前、标准在后。内容应互补，不显示相互矛盾的两个答案；冲突进入映射错误维护流程。
- 完全重复内容可在未来评估轻量去重，本轮不引入自动去重、折叠或修改释义文本。
- 维持第6、7版标签页规则，不为单一内容增加标签，不增加“旧版解释”类别。
- 阅读器、后端和夜间巡检只引用已有标准义项，不能创造 sense ID 或修改标准词典定义。

## 实施与验证边界

- WordSensePanel 为受控展示组件，不发送请求、不持久化、不查询贡献者。
- 演示保留内部样例计数用于验证改选、取消与位置隔离，但不在词卡展示。
- 未接真实标准词典、投票队列、社区审核或生词本迁移；不能将演示回执当作线上成功。
- 本版覆盖前版公开票数展示与点赞文案规则，其他数据权限及布局规则继续有效。
